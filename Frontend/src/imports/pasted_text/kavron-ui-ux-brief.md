Design and build a complete, premium, production-quality web application UI/UX for:

# KAVRON

### Intelligent Visual Security Platform

KAVRON is an AI-powered intelligent video analytics platform for **border surveillance using existing CCTV infrastructure**.

The platform transforms conventional IP-based CCTV feeds into an intelligent real-time surveillance network without requiring dedicated smart-camera hardware.

Core capabilities include:

* Real-time object detection
* Multi-object tracking
* Intrusion detection
* Virtual fencing and perimeter monitoring
* Automatic Number Plate Recognition (ANPR)
* Face analytics where applicable
* Suspicious activity detection
* Real-time event detection
* Automated alerts
* Multi-camera monitoring
* Incident investigation
* Command-center visualization
* Analytics and reporting

The design must feel like a **premium next-generation security intelligence product**.

IMPORTANT:

The entire interface must use a **LIGHT THEME**.

Do NOT create a dark dashboard.

Do NOT use a cyberpunk aesthetic.

Do NOT use military camouflage.

Do NOT create a generic admin dashboard.

Do NOT make the interface look like a college project.

Make KAVRON feel like a sophisticated commercial product that could realistically be deployed by a large security organization.
